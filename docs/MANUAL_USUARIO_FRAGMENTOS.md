# Fragmentos para el manual de usuario

Textos listos para copiar al manual de usuario final, escritos para la persona que usa el sistema
(no para el equipo). Se agregan fragmentos nuevos a medida que se van necesitando.

## Verificación en dos pasos

Si tu cuenta es de Administración o de Producción, puedes activar un paso extra de seguridad al
ingresar: además de tu contraseña, el sistema te pedirá un código de 6 dígitos desde tu teléfono.

**Cómo activarla:**
1. Instala una aplicación de verificación en tu teléfono, como Google Authenticator o Microsoft
   Authenticator (son gratis).
2. Ve a «Mi cuenta» → «Activar verificación en dos pasos».
3. Abre la aplicación de tu teléfono y escanea el código QR que aparece en pantalla.
4. Escribe el código de 6 dígitos que te muestra la aplicación y presiona «Confirmar y activar».

Desde ese momento, cada vez que ingreses con tu correo y tu contraseña, el sistema te pedirá además
ese código. Cambia cada 30 segundos, así que siempre usa el que esté en pantalla en ese momento.

**Si pierdes tu teléfono o cambias de equipo:** pídele a una persona de Administración que
desactive la verificación en dos pasos de tu cuenta. Después puedes volver a activarla desde un
teléfono nuevo siguiendo los mismos pasos de arriba.

**Para desactivarla tú mismo:** ve a «Mi cuenta» y presiona «Desactivar verificación en dos pasos».
Te pedirá tu contraseña actual para confirmar.
