Tabla para registrar, con capturas de pantalla reales (pgAdmin / mongosh / Compass), la ejecución
de las consultas de demostración de `docs/GUIA_BASES_DE_DATOS.docx`: C1-C8 (PostgreSQL), N1-N4
(MongoDB) y M1-M5 (mixtas, que cruzan ambos motores, como la relación `ref_documento` ↔ `_id`).

No se completa "de memoria": cada fila se llena solo después de ejecutar la consulta de verdad y
guardar la captura (nombre de archivo o ruta en la columna "Obtenido"). Mientras no se ejecute,
la fila queda vacía.
